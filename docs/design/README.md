# فایل طراحی

`panel-negin-misagh.html` نمونه HTML اولیه پنل است و مرجع رنگ‌ها، استایل کامپوننت‌ها و منطق صفحات است.
برای دیدن، فایل را مستقیم در مرورگر باز کنید (کاربر: `admin` / `admin`).

- پالت رنگ‌ها از متغیرهای `:root` این فایل در `src/theme/palette.ts` آمده است.
- این فایل فقط مرجع است و در build پروژه استفاده نمی‌شود؛ آن را ویرایش نکنید.
